מדריך למשתמש — PLC to Excel V0.1

הכלי קורא קובץ פרויקט של בקר ומפיק ממנו קובץ Excel מסודר: חומרה וכרטיסים, רשימת IO עם שמות, תגיות ומשתנים, בלוקים וקוד, הגדרות תקשורת ופרמטרים. קבצי הפרויקט המקוריים לעולם אינם משתנים.

התקנה

  1. הורד את PlcToExcel_Setup_V0.1.exe מ-Releases והפעל.
  2. בחר שפה, תיקיית התקנה, והאם להוסיף קיצור דרך בשולחן העבודה ו-"Export to Excel" ללחיצה ימנית.
  3. הסרה: הגדרות Windows ← אפליקציות ← PLC to Excel ← הסר.

דרישות: Windows 10/11 ‏64-bit. לקריאת פרויקטי TIA Portal נדרש TIA Portal V21 מותקן.

התחלה מהירה

  1. גרור קובץ פרויקט לחלון (או Ctrl+O, או לחיצה ימנית על הקובץ ← Export to Excel).
  2. בדוק את נתיב קובץ היעד (ברירת מחדל: ליד קובץ הפרויקט, <שם>_Export.xlsx).
  3. לחץ Export to Excel (או F5). הקובץ ייפתח ב-Excel בסיום.

אפשר לגרור כמה קבצים או תיקייה שלמה — כולם ייוצאו ברצף.

מה יש בקובץ ה-Excel

גיליון תוכן
Summary פרטי פרויקט, דגם בקר, IP, ספירות, הערות
Hardware כרטיסים: סלוט, מק"ט, קושחה, כתובות
IO_List כל ערוץ: כרטיס, DI/DO/AI/AO, ערוץ, כתובת, שם, הערה, שימוש בקוד
Tags / Variables / Symbols משתנים עם סוג, כתובת, ערך התחלתי והערה
Blocks / Networks_Code בלוקים וקוד (ST/SCL מלא; LAD/FBD — מגעים, סלילים ואופרנדים)
Network ממשקים, IP, מסכות, שמות PROFINET
Alarms_Protections (DSE) הגנות והתראות: פעולה, השהייה, ערכים

בכל גיליון: כותרת מוקפאת וסינון בכל עמודה.

סיסמאות והגנות

  • TIA — פרויקט מוגן (UMAC): חלון שם משתמש וסיסמה.
  • TIA — בלוקים מוגנים (Know-how): חלון סיסמה אחד; ההגנה מוסרת רק בעותק הזמני.
  • Control Expert — DFB מוגן: מוצפן ע"י Schneider; הממשק מיוצא, הקוד לא (גיליון Protected_Items).
  • DSE — PIN/סיסמה: מוצפנים בקובץ ואינם נדרשים; מוצגים כמוסתרים.

כל חלון סיסמה נסגר אוטומטית אחרי 10 דקות ללא קלט, והייצוא ממשיך עם כל מה שזמין.

TIA Portal

  • בשימוש הראשון TIA מציג Openness – Grant access ← לחץ Yes to all.
  • המשתמש צריך להיות בקבוצת Windows Siemens TIA Openness.
  • פתיחה: 1–2 דקות. פרויקטים V16–V20 משודרגים ומקומפלים בעותק זמני שנמחק בסיום.

אפשרויות

ערכת נושא בהירה/כהה/לפי Windows · פתיחת Excel/תיקייה בסיום · תאריך בשם הקובץ · תיקיית יעד קבועה · קבצים אחרונים · ייצוא מרובה. אם קובץ היעד פתוח ב-Excel — נשמר אוטומטית כ-_2, _3.
