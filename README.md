# PLC Com Tools — PLC to Excel

Export PLC projects (Schneider Control Expert, Siemens TIA Portal V16–V21, STEP 7-Micro/WIN SMART, Deep Sea Electronics) to structured Excel workbooks: hardware, IO list with signal names, tags, code and settings.

ייצוא פרויקטי בקרים לטבלאות Excel מסודרות.

- **Website / download:** https://bennymat93.github.io/PLC-Com-Tools/
- **Latest installer:** [PlcToExcel_Setup_V0.1.2.exe](https://github.com/bennymat93/PLC-Com-Tools/releases/latest/download/PlcToExcel_Setup_V0.1.2.exe)
- **User guide (Hebrew):** https://bennymat93.github.io/PLC-Com-Tools/guide.html

This repository hosts the download site and releases. Source code is private.
